# Fuentes recomendadas

Estas son algunas fuentes y plataformas que pueden proporcionar recursos académicos:

1. **Google Académico**  
   Permite buscar artículos científicos, tesis, libros y diferentes publicaciones académicas.

2. **SciELO**  
   Biblioteca electrónica que ofrece acceso a artículos científicos y revistas académicas de diferentes países.

3. **Redalyc**  
   Plataforma que proporciona artículos y revistas científicas, principalmente de América Latina, el Caribe, España y Portugal.

4. **Dialnet**  
   Base de datos especializada en artículos, revistas, libros y tesis de diferentes áreas del conocimiento.

5. **JSTOR**  
   Plataforma que ofrece acceso a artículos académicos, libros y fuentes de investigación de diversas disciplinas.

6. **Microsoft Academic**  
   Plataforma utilizada para consultar publicaciones y trabajos de investigación académica.

7. **PubMed**  
   Base de datos especializada principalmente en investigaciones relacionadas con medicina, ciencias de la salud y biología.
