
# Fuentes Recomendadas

1. **Google Scholar / Google Académico**: Plataforma de búsqueda para localizar literatura académica, artículos de revistas, tesis y libros científicos.
2. **Coursera**: Plataforma de educación en línea que ofrece cursos, especializaciones y recursos de universidades de alto prestigio mundial.
3. **MDN Web Docs**: Documentación técnica oficial y actualizada sobre tecnologías web como HTML, CSS, JavaScript y estándares web.
4. **W3Schools**: Portal educativo interactivo con tutoriales, referencias y ejercicios prácticos de lenguajes de programación y desarrollo web.
5. **Kaggle**: Comunidad global de ciencia de datos y aprendizaje automático que provee datasets gratuitos, notebooks y cursos interactivos.
